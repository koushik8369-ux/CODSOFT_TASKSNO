
# CodSoft Task 2 — Student Grade Calculator

## About
A Java console application that calculates total marks,
average percentage, and the corresponding grade.

## Features
- Accepts marks for multiple subjects
- Validates marks from 0 to 100
- Calculates total and average percentage
- Assigns grades based on average percentage
- Handles invalid input

## Technologies
- Java
- Scanner
- Loops and conditional statements
- Methods and input validation

## Run the Project

Compile:
```bash
javac -Xlint:all -d out src/StudentGradeCalculator.java
```

Run:
```bash
java -cp out StudentGradeCalculator
```

## Grade Scale
- A+: 90% and above
- A: 80%–89.99%
- B: 70%–79.99%
- C: 60%–69.99%
- D: 50%–59.99%
- F: Below 50%

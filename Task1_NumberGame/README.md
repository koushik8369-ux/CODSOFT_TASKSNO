
# CodSoft Task 1 - Number Game

## About the Project
A console-based Number Guessing Game developed in Java
as part of the CodSoft Java Development Internship.

## Features
- Generates a random number between 1 and 100
- Provides higher and lower hints
- Limits each round to 7 valid guesses
- Supports multiple rounds
- Tracks rounds won and total rounds played
- Handles invalid non-numeric input
- Validates guesses outside the allowed range

## Technologies Used
- Java
- Random class
- Scanner class
- Loops and conditional statements
- Input validation

## Project Structure

Task1_NumberGame/
├── src/
│   └── NumberGame.java
├── README.md
└── out/ (generated compiled files)

## How to Run

Compile:

```bash
javac -Xlint:all -d out src/NumberGame.java
```

Run:

```bash
java -cp out NumberGame
```

- Generating random numbers
- Using loops and conditional logic
- Handling user input
- Validating input
- Tracking scores and attempts
